# Sistema-de-Gerenciamento-de-Funcion-rios

Desenvolvi um programa em Java que permite ao usuário cadastrar funcionários de uma empresa, armazenando informações como ID, nome e salário. O sistema também realiza o tratamento de IDs duplicados e de possíveis erros que possam ocorrer durante a execução.

Durante o desenvolvimento, utilizei conceitos de Programação Orientada a Objetos (POO), classes, polimorfismo, expressões lambda e estruturas de repetição.

Pretendo evoluir o projeto gradualmente, implementando um banco de dados e adicionando novas funcionalidades para torná-lo mais completo e próximo de uma aplicação real.
